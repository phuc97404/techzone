# 💡 TechZone - Ý Tưởng & Ghi Chú

## Mô tả
Website thương mại điện tử bán linh kiện máy tính, lấy cảm hứng từ memoryzone.com.vn.
Full-stack Next.js, deploy trên Vercel.

## Nhóm sản phẩm
- CPU
- Mainboard
- GPU (Card đồ họa)
- RAM
- SSD
- Phụ kiện (chuột, bàn phím, tai nghe)
- Màn hình

## Tính năng chính

### 🏠 Trang chủ
- Banner quảng cáo
- Sản phẩm nổi bật
- Khuyến mãi
- RAM hot
- SSD hot

### 📦 Trang sản phẩm
- Hình ảnh sản phẩm
- Giá
- Thông số kỹ thuật
- Đánh giá từ người dùng
- Sản phẩm liên quan

### 🔍 Tìm kiếm & Filter
- Theo giá
- Theo hãng
- Theo socket CPU
- Theo dung lượng RAM

### 🛒 Giỏ hàng
- Add to cart
- Checkout

### ⚙️ CMS / Admin
- Quản lý sản phẩm
- Quản lý đơn hàng
- Tồn kho
- Khuyến mãi
