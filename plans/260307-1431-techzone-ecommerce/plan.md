Created: 2026-03-07T14:31:25+07:00

## Overview
Website thương mại điện tử bán linh kiện máy tính (CPU, Mainboard, GPU, RAM, SSD, Phụ kiện, Màn hình).
Full-stack Next.js 15 App Router, deploy trên Vercel. Giao diện lấy cảm hứng từ memoryzone.com.vn.

## Tech Stack
- **Framework:** Next.js 15 (App Router) - TypeScript
- **Database:** PostgreSQL (Neon Serverless)
- **ORM:** Prisma
- **Auth:** NextAuth.js v5
- **Styling:** CSS Modules + CSS Variables (Dark/Light theme)
- **State Management:** Zustand (Cart, Filters)
- **Image Hosting:** Cloudinary / Next/Image
- **Deploy:** Vercel
